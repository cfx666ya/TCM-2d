## 📖 项目简介

本作品为一款中医药主题游戏，背景设置为玩家置身于中医药博物馆内参观，以玩家的参观流程为主线串联起多个中医药历史人物，并根据人物的突出事迹、积极贡献、中医药精神及其代表著作等，精心设计符合历史事实的诸多形式小游戏，包括**剧情互动、益智闯关、术语接龙、知识问答、迷宫寻宝**等，想法独特，创意新颖。

游戏规则简单、难度适中、玩法丰富、易于传播，让玩家在沉浸式体验中医药文化魅力的同时产生浓厚兴趣，**寓教于乐**，以此达到传承与发展中医药文化、增强民族文化自信的作用。

## ✨ 游戏特色

- **立足史实**：游戏围绕钱乙、张仲景、华佗、扁鹊、孙思邈五位中国历史上具有代表性的名医的经历和治疗理念而展开，内容均源于史书记载与正版著作，参考了扁鹊的《难经》、钱乙的《小儿药证直诀》、孙思邈的《千金要方》、张仲景的《伤寒杂病论》等极具影响力的中医药代表著作。
- **寓教于乐**：将中医药史上的里程碑事件巧妙地转化为休闲小游戏，如迷宫、寻宝、解谜等，让玩家在休闲娱乐的同时加深对中医药的认识。
- **玩法多样**：集剧情、闯关、问答、解谜等当下流行的游戏形式于一体，玩法丰富多样，消除游戏的枯燥感，激发玩家的探索欲。
- **易于传播**：游戏规则简单、难度合理，各年龄段的玩家都能轻松上手。

## 🕹️ 操作说明

### 博物馆内操作
- 使用键盘方向键 / WASD 控制参观者在博物馆内移动。
- 靠近名医画像时弹出"进入互动？"对话框，点击 **"是"** 进入名医简介窗口，点击 **"否"** 继续参观。
- 简介窗口中点击 **"进入"** 进入篇章选择界面，点击下方标签进入对应篇章，点击右上角 **"返回"** 回到博物馆。

### 各篇章操作
- **通用移动**：键盘方向键 / WASD 控制角色移动。
- **五禽戏**：按 **W / A / S / D / X** 施展虎、鹿、熊、猿、鸟五种禽兽姿态。
- **麻沸散**：按 **J** 释放中医药，按 **K** 释放麻沸散。
- **医治病人**：按 **空格键** 释放中草药命中病人。
- **开始界面**：点击 **"开始"** 进入博物馆，点击 **"退出"** 退出游戏。

> 不同关卡篇章操作有所不同，详见游戏内提示与上述说明文档。

## 🚀 快速开始（使用方法）

### 方式一：使用 Unity 编辑器运行

1. 安装 **Unity Hub** 与 **Unity 2021.3.6f1**（LTS 版本）。
2. 克隆或下载本项目，并解压到本地。
   ```bash
   git clone <你的仓库地址>
   ```
3. 打开 **Unity Hub** → **添加项目** → 选择本项目的根目录（包含 `Assets`、`ProjectSettings`、`Packages` 文件夹的目录）。
4. 等待 Unity 导入并解析依赖（首次打开需要一些时间）。
5. 打开场景 `Assets/Scenes/Start.unity`（开始界面）。
6. 点击编辑器顶部的 **▶ Play** 按钮即可开始游戏。

### 方式二：构建为独立可执行程序

1. 打开 **File → Build Settings**。
2. 选择目标平台（如 **Windows** 或 **macOS**）。
3. 点击 **Build**，选择输出目录。
4. 运行生成的可执行文件即可游玩。

> 如需自定义主场景顺序，可参考 `ProjectSettings/EditorBuildSettings.asset` 中已配置好的场景列表。
